# Zinc Hub

Zinc Hub is a branding fork of Forsaken Plus v2.0 by **Naiko Scripts**.

## Source

- Script: [ZincHub.lua](./ZincHub.lua)
- Original: https://naikoscripts.pages.dev/ForsakenPlus

The sidebar and menu are named Zinc Hub. Original functionality, settings paths, and the shared duplicate-run guard are preserved. The original author's credits remain in the source and UI.

## Attribution and redistribution

The upstream source states: "Copies of this script must contain the original credits and be open source". Keep those credits and this source available when redistributing. This fork does not claim authorship of the original script or add a replacement license.

## Validation

The changes were checked to contain only branding substitutions and provenance comments. Runtime behavior has not been tested in Roblox; this is not a claim of compatibility or a security audit.
